# Ventoy Manager Studio

**Единая платформа для установки, настройки, оформления и управления загрузочными USB-накопителями на базе Ventoy.**

Ventoy Manager Studio — это Windows-приложение, объединяющее все основные инструменты для создания и обслуживания мультизагрузочных USB-флешек на базе [Ventoy](https://www.ventoy.net/).

Проект объединяет загрузку и установку Ventoy, обновление загрузчика, управление USB-накопителями, организацию загрузочных образов, редактирование конфигурации, визуальное оформление загрузочного меню GRUB, диагностику и резервное копирование.

Вместо использования множества отдельных утилит, ручного редактирования конфигурационных файлов и самостоятельного поиска ресурсов пользователь получает единую графическую среду управления всей загрузочной системой.

---

## Концепция проекта

Наша цель — создать полноценную платформу управления Ventoy, которая превращает обычную загрузочную флешку в гибкую, организованную и полностью настраиваемую мультизагрузочную систему.

Ventoy Manager Studio — это не просто редактор конфигурации или инструмент изменения внешнего вида меню.

Это единая система управления полным жизненным циклом Ventoy USB:

- Первоначальная подготовка накопителя.
- Загрузка и установка Ventoy.
- Обновление установленной версии.
- Организация загрузочных образов.
- Создание и настройка загрузочного меню.
- Визуальное оформление GRUB.
- Управление конфигурациями и ресурсами.
- Диагностика и проверка работоспособности.
- Резервное копирование и восстановление.

## Основные возможности

### 1. Установка и обновление Ventoy
- Автоматическое обнаружение последней стабильной версии Ventoy.
- Загрузка официальных дистрибутивов.
- Проверка целостности загруженных файлов.
- Определение установленной версии.
- Установка Ventoy на выбранный USB-накопитель.
- Обновление существующей установки.
- Проверка совместимости конфигураций.
- Защита пользовательских данных при обслуживании накопителя.

### 2. Управление USB-накопителями
- Автоматическое обнаружение подключённых USB-устройств.
- Отображение объёма, разделов и файловых систем.
- Определение основного раздела Ventoy и системного раздела VTOYEFI.
- Анализ структуры накопителя.
- Поддержка нескольких Ventoy-флешек.
- Контроль состояния и целостности накопителей.

### 3. Менеджер загрузочных образов и файлов
- Автоматическое сканирование загрузочных образов.
- Поддержка ISO, WIM, IMG, VHD, VHDX и других форматов, поддерживаемых Ventoy.
- Создание папок и категорий.
- Перемещение, переименование и организация файлов.
- Настройка отображаемых названий независимо от физических имён файлов.
- Управление видимостью пунктов загрузочного меню.
- Назначение иконок и изменение порядка отображения.

### 4. Визуальный редактор загрузочного меню
- Организация структуры загрузочного меню.
- Создание логических категорий и групп в рамках возможностей Ventoy.
- Настройка названий и иконок.
- Управление поддерживаемыми плагинами Ventoy.
- Работа с элементами image_list, menu_alias и menu_class.
- Настройка порядка и представления загрузочных пунктов.

### 5. GRUB Theme Studio
- Визуальное редактирование оформления загрузочного меню.
- Настройка фоновых изображений и логотипов.
- Управление шрифтами и цветами.
- Настройка размеров и расположения элементов.
- Редактирование файлов theme.txt.
- Управление ресурсами и зависимостями темы.
- Предварительный просмотр изменений.

### 6. Редактор конфигурации Ventoy
- Визуальное и текстовое редактирование ventoy.json.
- Проверка синтаксиса JSON.
- Работа с документированными плагинами и настройками Ventoy.
- Сохранение неизвестных параметров конфигурации.
- Проверка путей и ссылок на ресурсы.
- Создание резервных копий перед изменениями.

### 7. Резервное копирование и восстановление
- Автоматическое создание резервных копий.
- Сохранение истории изменений.
- Восстановление предыдущих конфигураций.
- Защита пользовательских тем и ресурсов.
- Контроль операций с файлами и настройками.
- Возможность возврата к предыдущему состоянию.

### 8. Диагностика и контроль системы
- Проверка установленной версии Ventoy.
- Анализ структуры USB-накопителя.
- Проверка конфигурационных файлов.
- Поиск отсутствующих ресурсов.
- Проверка ссылок и зависимостей оформления.
- Выявление потенциальных ошибок.
- Подробный журнал операций и диагностики.

## Принципы разработки

**Единая система управления**

Все основные инструменты работы с Ventoy объединяются в одном приложении.

**Автоматизация**

Программа самостоятельно определяет накопители, версии Ventoy, структуру файлов и доступные ресурсы.

**Безопасность**

Любые потенциально опасные операции требуют подтверждения. Конфигурации резервируются перед изменением.

**Совместимость**

Приложение учитывает различия между версиями Ventoy и не использует неподтверждённые параметры конфигурации.

**Сохранность пользовательских данных**

Пользовательские настройки, темы, ресурсы и папка приложения должны сохраняться при обычном обновлении Ventoy.

**Модульность**

Каждая функциональная часть разрабатывается как отдельный модуль с возможностью дальнейшего расширения.

**Автономность**

Приложение должно поддерживать локальную работу без постоянного подключения к интернету. Интернет используется только для операций, которым он действительно необходим, например загрузки официальных обновлений.

## Технологии

- Python — серверная логика и системные операции.
- HTML5 — структура интерфейса.
- CSS3 — визуальное оформление.
- Vanilla JavaScript — интерактивность и управление интерфейсом.
- REST API — взаимодействие между интерфейсом и backend.
- Windows 10 / Windows 11 — целевая операционная система.

В перспективе — создание самостоятельной версии приложения в формате `.exe`, не требующей установленного Python.
