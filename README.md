# Ventoy Manager Studio

**Единый центр управления Ventoy: установка, обновление, организация загрузочных образов, настройка меню и оформление GRUB в одном Windows-приложении.**

Ventoy Manager Studio — независимый проект, цель которого — сделать работу с [Ventoy](https://www.ventoy.net/) удобнее и понятнее. Приложение разрабатывается как единая графическая среда для подготовки USB-накопителей, управления установленным Ventoy, настройки загрузочного меню и обслуживания пользовательской конфигурации.

Вместо набора разрозненных утилит и ручного редактирования нескольких файлов пользователь сможет выполнять основные операции из одного интерфейса.

> **Важно:** проект находится на ранней стадии разработки. Описанные ниже возможности — целевое видение и планируемая функциональность, а не заявление о том, что все модули уже реализованы.

## Цель проекта

Создать полноценную платформу для управления всем жизненным циклом Ventoy USB:

1. Найти и загрузить официальный выпуск Ventoy.
2. Подготовить выбранный USB-накопитель и установить Ventoy.
3. Обнаруживать установленную версию и проверять состояние накопителя.
4. Обновлять Ventoy штатным способом.
5. Организовывать загрузочные образы, файлы и каталоги.
6. Настраивать отображение загрузочных пунктов.
7. Редактировать конфигурацию Ventoy и оформление GRUB.
8. Создавать резервные копии, проверять настройки и восстанавливать их при необходимости.

Ключевая идея — не просто редактор `ventoy.json`, а единый **Ventoy Control Center** с понятным рабочим процессом от первой установки до ежедневного обслуживания флешки.

## Основные возможности

Все перечисленные ниже функции входят в целевой объём проекта. Их реализация будет происходить поэтапно.

### 1. Загрузка, установка и обновление Ventoy

- Получение информации об официальных релизах Ventoy.
- Поиск последней стабильной версии и отображение истории версий.
- Загрузка официального дистрибутива и проверка его целостности по доступным контрольным суммам.
- Выбор USB-накопителя и отображение сведений о нём до начала операции.
- Первоначальная установка Ventoy.
- Определение установленной версии.
- Обновление существующей установки с использованием штатных средств Ventoy.
- Проверка результата установки или обновления.

### 2. Управление USB-накопителями

- Обнаружение подключённых накопителей.
- Отображение модели, объёма, разделов и файловых систем.
- Определение основного раздела с пользовательскими файлами и системного раздела `VTOYEFI`.
- Определение наличия Ventoy и доступной информации о его версии.
- Анализ структуры накопителя.
- Работа с несколькими накопителями и их отдельными профилями.

### 3. Менеджер загрузочных образов и файлов

- Сканирование содержимого основного раздела.
- Поиск загрузочных образов, включая ISO, WIM, IMG, VHD и VHDX.
- Просмотр файлов и папок, поиск, фильтрация и сортировка.
- Создание каталогов и организация файлов.
- Перемещение и переименование с проверкой связанных конфигурационных ссылок.
- Настройка отображаемого названия загрузочного пункта независимо от физического имени файла — если это поддерживается соответствующим механизмом Ventoy.
- Управление иконками, категориями и видимостью пунктов в пределах документированных возможностей Ventoy.

### 4. Редактор загрузочного меню

- Визуальная организация загрузочных пунктов.
- Настройка названий, иконок и классов меню.
- Управление поддерживаемыми механизмами Ventoy, включая `image_list`, `menu_alias` и `menu_class`, в соответствии с официальной документацией.
- Проверка корректности путей и ссылок.
- Сохранение исходных параметров, которые редактор пока не умеет отображать визуально.

### 5. GRUB Theme Studio

- Просмотр и редактирование `theme.txt`.
- Настройка фона, логотипов, шрифтов и цветов.
- Настройка расположения и размеров поддерживаемых элементов.
- Управление изображениями, шрифтами PF2 и другими ресурсами темы.
- Анализ зависимостей и поиск отсутствующих файлов.
- Предварительный просмотр оформления.

Предпросмотр будет обозначаться как визуальная оценка темы, а не как полная эмуляция GRUB: отдельные эффекты и особенности реального загрузчика могут отображаться иначе.

### 6. Редактор конфигурации Ventoy

- Открытие и редактирование `ventoy/ventoy.json`.
- Визуальный редактор и режим исходного JSON.
- Проверка синтаксиса перед сохранением.
- Работа с документированными плагинами Ventoy.
- Проверка путей к образам, скриптам и ресурсам.
- Сохранение неизвестных или неподдерживаемых редактором ключей без потери данных.

### 7. Резервное копирование и восстановление

- Создание резервных копий перед изменением важных конфигураций.
- Сохранение пользовательских тем, ресурсов и настроек приложения.
- История изменений и журнал операций.
- Восстановление предыдущей конфигурации.
- Проверка резервной копии перед восстановлением.

### 8. Диагностика и совместимость

- Проверка структуры накопителя и наличия необходимых файлов.
- Определение версии Ventoy.
- Проверка JSON и конфигурационных ссылок.
- Поиск отсутствующих ресурсов темы.
- Выявление потенциально несовместимых настроек.
- Понятные сообщения об ошибках и диагностические журналы.

## Безопасность и сохранность данных

Операции с USB-накопителями могут привести к потере данных. Поэтому безопасность — обязательное требование к архитектуре приложения.

- **Никакой установки без подтверждения.** Перед началом установки пользователь должен видеть выбранное устройство и предупреждение о возможной потере данных.
- **Различать установку и обновление.** Обычное обновление Ventoy нельзя подменять повторной установкой или форматированием.
- **Не выбирать накопитель автоматически.** Пользователь должен явно подтвердить целевое устройство.
- **Не изменять системный раздел без необходимости.** Раздел `VTOYEFI` должен обнаруживаться и проверяться, но не редактироваться вручную в обычном рабочем процессе.
- **Сохранять пользовательские данные.** Папка приложения, настройки, темы и образы не должны затрагиваться обычными операциями обновления Ventoy.
- **Создавать резервные копии.** Перед изменением конфигураций необходимо сохранять исходное состояние.
- **Проверять пути.** Файловые операции должны быть ограничены выбранным накопителем и не допускать случайного выхода за его пределы.
- **Показывать результат честно.** Приложение не должно сообщать об успешной операции, если проверка результата не пройдена.

Сохранность файлов при конкретной операции должна проверяться с учётом используемого официального механизма Ventoy. Нельзя обещать сохранение данных при форматировании или переустановке.

## Принципы совместимости

Ventoy Manager Studio должна опираться на официальные релизы и документацию Ventoy.

- Не использовать выдуманные параметры конфигурации.
- Учитывать различия между версиями Ventoy.
- Проверять поддержку плагинов и настроек.
- Не удалять неизвестные поля из JSON.
- Не перезаписывать неподдерживаемые директивы GRUB.
- При неопределённости предупреждать пользователя, а не выполнять потенциально опасное преобразование.

## Технологии и архитектура

Целевая платформа — **Windows 10 и Windows 11**.

Предполагаемый технологический стек:

| Технология | Назначение |
|---|---|
| Python | Backend, системные операции и работа с Ventoy |
| HTML5 | Структура пользовательского интерфейса |
| CSS3 | Стили и адаптивная компоновка |
| Vanilla JavaScript | Интерактивность интерфейса |
| REST API | Обмен данными между frontend и backend |
| GitHub | Исходный код, контроль версий и релизы |

Архитектура будет модульной: обнаружение USB, загрузчик Ventoy, установка и обновление, файловый менеджер, редакторы конфигурации, дизайнер тем, диагностика и резервное копирование должны развиваться независимо друг от друга.

В перспективе планируется сборка самостоятельного Windows-приложения в формате `.exe`, не требующего предварительной установки Python.

Основные функции управления накопителем и редактирования локальных конфигураций должны работать без интернета. Сеть потребуется для получения релизов и обновлений.

## План разработки

| Этап | Результат |
|---|---|
| 01. Основа | Архитектура приложения, интерфейс, журналирование и диагностика |
| 02. Ventoy Downloader | Получение официальных релизов и проверка загруженных файлов |
| 03. USB Manager | Обнаружение накопителей, разделов и установленных версий |
| 04. Установка и обновление | Безопасная интеграция со штатными средствами Ventoy |
| 05. File & ISO Manager | Сканирование, поиск и организация файлов |
| 06. Config & Menu Editor | Редактирование `ventoy.json` и настройка загрузочного меню |
| 07. GRUB Theme Studio | Редактор тем, ресурсов и зависимостей |
| 08. Preview | Визуальный предпросмотр оформления |
| 09. Backup & Recovery | Резервирование, восстановление и история изменений |
| 10. Release | Тестирование, оптимизация и сборка Windows-приложения |

Порядок и состав этапов могут уточняться по мере разработки, но безопасность операций с накопителями остаётся обязательным требованием на каждом этапе.

## Статус проекта

**Реализована первая техническая основа приложения (Foundation 0.1.0).**

Уже добавлено в репозиторий:
- локальный Python HTTP-сервер на стандартной библиотеке Python;
- интерфейс Ventoy Manager Studio на HTML, CSS и Vanilla JavaScript;
- локальные API-эндпоинты состояния приложения и системной информации;
- обнаружение физических дисков, разделов и томов Windows через PowerShell в режиме только чтения;
- отображение дисков и разделов в интерфейсе;
- стартовый файл `start.bat` и базовый набор автоматических тестов.

**Пока не реализовано:** загрузка релизов Ventoy, достоверное распознавание установленной версии Ventoy, установка и обновление, файловые операции, редакторы конфигурации и тем, резервное копирование. Пункты меню для этих модулей обозначают будущие разделы и не имитируют их работу.

### Запуск из исходного кода

1. Установите Python 3.10 или новее.
2. Скачайте репозиторий или клонируйте его на компьютер с Windows 10/11.
3. Запустите `start.bat`.
4. Приложение откроется в браузере по адресу `http://127.0.0.1:5454`.

Внешние Python-пакеты для текущей основы не требуются. Сервер доступен только на локальном интерфейсе компьютера.

### Проверка тестов

```powershell
python -m unittest discover -s tests -v
```

Текущая версия не выполняет запись на диски, форматирование или изменение разделов. Перед реализацией таких операций будут добавлены отдельные проверки, подтверждения и тесты на изолированных тестовых накопителях.
